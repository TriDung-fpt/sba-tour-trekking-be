## Còn lại (khi được approve chạy)
1. `docker info` — Docker Desktop đã start trước đó; nếu chưa ready thì chờ daemon.
2. Chạy 2 test riêng:
   `.\mvnw.cmd test "-Dtest=AccountAdministrationIntegrationTests#nonAdminRolesAreDeniedListUpdateAndAuditLogEndpoints+adminListsFiltersUpdatesProfileWithAuditAndCannotUpdateSelf" -DfailIfNoTests=false`
3. Nếu fail → sửa đúng đoạn lỗi, compile lại, chạy lại test đó (không chạy toàn bộ suite).
4. Báo cáo ≤10 dòng: file tạo/sửa, endpoint mới, phần chưa làm — rồi DỪNG.
